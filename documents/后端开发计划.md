# LLM评估数据集管理系统 - 简化版后端开发计划

## 项目概述

基于Spring Boot 3.x的简化版LLM评估数据集管理系统，专注于必须实现的核心功能，降低开发复杂度，确保在有限时间内完成可用的系统。

---

## 技术栈选择

### 核心框架
- **Spring Boot 3.2+**: 主框架，提供自动配置和约定优于配置
- **Spring Data JPA**: ORM和数据访问，简化数据库操作
- **Spring Web**: RESTful API开发
- **Spring Validation**: 参数校验

### 数据库
- **MySQL 8.0+**: 主数据库
- **H2**: 开发和测试环境（可选）

### 工具库
- **ModelMapper**: DTO映射，减少手动转换代码
- **Lombok**: 减少样板代码
- **OpenAPI 3 (SpringDoc)**: API文档自动生成

### 开发工具
- **Maven**: 依赖管理
- **JUnit 5**: 单元测试（核心功能）

## 开发阶段划分

### 阶段1: 项目基础搭建 (1-2天)

#### 1.1 项目初始化
- 创建Spring Boot项目
- 配置基本依赖 (pom.xml)
- 配置数据库连接
- 设置基本的配置文件

#### 1.2 基础架构
- 创建基础Entity、DTO、Repository、Service、Controller抽象类
- 配置ModelMapper
- 设置全局异常处理
- 配置OpenAPI文档

#### 1.3 数据库初始化
- 创建数据库迁移脚本
- 定义所有实体类和枚举
- 验证数据库连接和表创建

### 阶段2: 原始问答模块 (2-3天)

#### 2.1 核心实体和Repository
- 实现 `RawQuestion` 和 `RawAnswer` 实体
- 创建对应的Repository接口
- 编写基本的CRUD操作

#### 2.2 Service层实现
- `RawQuestionService`: 导入、查询、状态更新
- `RawAnswerService`: 导入、查询
- 重点实现XML/CSV导入功能（简化版）

#### 2.3 Controller层和API
- `RawQuestionController`: 基本CRUD和导入API
- `RawAnswerController`: 基本CRUD和导入API
- API文档和测试

#### 实现优先级
1. **必须**: 导入原始问题/答案、分页查询、基本统计
2. **重要**: 状态管理、查询过滤
3. **可选**: 高级搜索、批量操作

## 实施建议

### 开发原则
1. **MVP优先**: 每个阶段都实现最小可用功能
2. **简化设计**: 避免过度工程化，专注核心需求
3. **快速迭代**: 每个模块完成后立即测试和调整
4. **文档同步**: 边开发边更新API文档

### 风险控制
1. **时间预算**: 为每个阶段预留20%的缓冲时间
2. **功能裁剪**: 准备好可以删减的功能列表
3. **技术风险**: 复杂功能用简单方案替代
4. **数据处理**: 导入功能可以先手动预处理数据

### 测试策略
1. **手动测试**: 每个API完成后立即手动测试
2. **集成测试**: 关键流程的端到端测试
3. **数据验证**: 重点测试数据完整性和约束
4. **性能测试**: 分页查询和导入功能的基本性能测试
